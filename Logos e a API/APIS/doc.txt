Documentação da API HomeFin
Guia operacional com endpoints detalhados, campos obrigatórios e exemplos do Swagger

Versão do contrato: 1.0.1
Base URL: https://api.homefin.com.br/external
Fonte principal: Swagger + planilha de obrigatoriedade enviada



Objetivo deste material
 Este material consolida o contrato Swagger da API HomeFin em um guia de consulta rápida. A leitura
 foi organizada por operação, com foco em uso prático: finalidade, parâmetros de rota, campos da
 requisição, obrigatoriedade, exemplo existente no Swagger e respostas esperadas.


 Nos endpoints PUT, o entendimento adotado neste documento é: caso seja necessário atualizar dados
 já cadastrados, utilize a rota de atualização correspondente. Como o contrato fornecido não explicita
 atualização parcial versus envio completo do objeto, a recomendação operacional é validar com a
 HomeFin se o comportamento esperado é patch-like ou substituição mais ampla do payload.

POST /auth/token - Autenticação e geração de token
Utilize esta rota para envio/criação conforme o fluxo da integração.

Corpo da requisição
Content-Type: application/json | Schema: AuthRequest

Campo                                Obrig.                  Tipo                   Descrição

secretId                             S                       string                 Secret Id.

secretKey                            S                       string                 Secret Key.


Campos obrigatórios em destaque
Campo                                          Tipo                    Descrição

secretId                                       string                  Secret Id.

secretKey                                      string                  Secret Key.


Exemplo do Swagger
   {
       "secretId": "Secret ID",
       "secretKey": "Secret Key"
   }
