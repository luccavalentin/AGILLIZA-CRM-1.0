# Agilliza correspondente nas lojas

Casca Capacitor que abre o sistema em `https://crm.agillizatech.com.br/auth`. Não há segunda base de
código: mudança de tela sai pelo servidor. Mudança nativa exige novo pacote e nova revisão.

Pacote e Bundle ID: `br.com.agillizatech.correspondente` (não mudam depois do primeiro envio).
A chave de upload fica em `segredos/android/agilliza.jks`, fora do Git.
